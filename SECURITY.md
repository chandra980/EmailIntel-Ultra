# Security Policy

EmailIntel Ultra is a passive/public OSINT framework. Providers must not implement credential stuffing, password testing, authentication bypass, CAPTCHA bypass, rate-limit evasion, session theft, private inbox access, or stolen-credential validation.

Providers must use public/anonymous access, bounded timeouts, safe URL handling, explicit status semantics, and sanitized output. HTTP 200 alone is never proof of an account match.
